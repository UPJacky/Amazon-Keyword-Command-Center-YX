## 必须保留的旧证据

- 旧 task/run 不删除、不覆盖，作为历史基线。
- 广告报表展示、点击、订单、花费、销售额对账差值为零的证据继续有效。
- 登录、RLS、私有 Storage、报告门禁、随机对象名和未登录 API 拒绝证据继续有效。

## 新阶段完成判定

后续每一张任务卡都必须有源码或配置变更、针对性测试、产物或契约证据；不能仅凭页面打开、数组非空、状态为 partial、HTTP 200 或旧提交文字通过。

完整业务 Gate 还必须满足：

1. 生产入口能说明每个模块的数据来源、采样时间、版本和缺失原因。
2. 自然位、竞对、图片、广告实体模块要么有真实证据，要么明确失败或未生成原因；不能伪造 ready。
3. 新发布版本必须产生新的 task/run，不能覆盖旧 run。
4. 最终必须逐页核对六模块、规则与安全门禁，并记录可复核证据。
